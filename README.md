# Plantespil 🪴

Et browserspil om at pleje og passe kødædende planter — vand din Venusfluefanger med regnvand, fang fluer til den, og se den vokse fra frø til blomstrende plante.

Projektet er i planlægningsfasen. Scope, mekanikker, teknisk arkitektur og faseplan ligger i **[PLAN.md](PLAN.md)**.

## Status

- [x] Scope og implementeringsplan
- [ ] Fase 0 — projektfundament (Vite + Svelte + TypeScript, CI, deploy)
- [ ] Fase 1 — MVP: én plante der kan passes og gemmes
- [ ] Fase 2 — minispil, vejr og spilfølelse
- [ ] Fase 3 — flere arter, valuta og drivhus
- [ ] Fase 4 — årstider, dvale og blomstring
